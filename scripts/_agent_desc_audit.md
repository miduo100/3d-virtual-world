## 八、回填 SQL（**dry-run 预览，脚本未执行**）

等 A 类模型描述填好后，执行下面这条把描述同步到已有对象：

```sql
-- 只回填「对象描述为空」的行，不覆盖已手写的对象级描述
UPDATE world_objects wo
SET agent_description = um.description, updated_at = NOW()
FROM uploaded_models um
WHERE wo.model_path = um.path
  AND um.description IS NOT NULL
  AND um.description <> ''
  AND wo.agent_description IS NULL;
```

> 执行前建议先 `SELECT COUNT(*)` 同条件预览影响行数；执行后重跑本审计脚本复核。
